# مصحف

تطبيق مصحف إلكتروني **بسيط وخفيف**، يعمل بالكامل **بدون إنترنت**، **بدون إعلانات** و**بدون تتبّع**.

مبني بملفات ويب عادية فقط (HTML + CSS + JavaScript) — بدون أي مكتبات أو أدوات بناء.

## المميزات

- تصفّح المصحف كاملاً بترتيب صفحات مصحف المدينة (٦٠٤ صفحات)
- فهرس السور الـ١١٤ وفهرس الأجزاء الـ٣٠
- حفظ آخر صفحة تلقائياً والعودة إليها عند فتح التطبيق
- بحث في نص القرآن (يعمل بدون تشكيل)
- ثلاثة مظاهر: فاتح، ورقي، ليلي
- التحكم في حجم الخط
- خيار إبقاء الشاشة مضاءة أثناء القراءة
- قابل للتثبيت على الجوال كتطبيق (PWA)

## التشغيل محلياً

التطبيق ملفات ثابتة فقط، يكفي تشغيل أي خادم بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

> لا تفتح `index.html` مباشرة بالنقر المزدوج — المتصفح يمنع تحميل ملف البيانات من نظام الملفات.

## بنية المشروع

```
index.html              الواجهة
app.css                 التنسيق والألوان
app.js                  كل منطق التطبيق
sw.js                   Service Worker (العمل بدون إنترنت)
manifest.webmanifest    إعدادات التثبيت على الجوال
data/quran.json         نص المصحف كاملاً + أرقام الصفحات والأجزاء
fonts/                  خط Amiri Quran
icons/                  أيقونات التطبيق
```

### شكل ملف البيانات

```jsonc
{
  "surahs": [{ "n": 1, "name": "الفاتحة", "tr": "Al-Fatihah", "type": "مكية", "c": 7, "p": 1 }],
  "pages":  [[0, 6], ...],                          // ٦٠٤ صفحة: [أول آية, آخر آية]
  "juz":    [1, 22, 42, ...],                       // أول صفحة في كل جزء
  "verses": [[1, 1, 1, 1, "بِسۡمِ ٱللَّهِ …", 0]]   // [سورة, آية, صفحة, جزء, النص, سجدة]
}
```
